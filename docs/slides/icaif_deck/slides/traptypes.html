Where do the 17 points come from? Boundary and ambiguity. On E, R-PAL plus still accepts 30%, we accept 8.3%. On I, 80% versus 21.7%. Those are the cases where correctness depends on an executable check or an unstated convention. On missing fields and blatant out-of-scope asks, a prompt already refuses, and we are no better. Plain R-PAL, which only executes code, answers 48.8% of all traps. If asked why not just prompt the checks: R-PAL plus names the problem 65.4% of the time but takes the matching action only 55.8%. VerifiQuant goes from 76.7 to 75.4.
