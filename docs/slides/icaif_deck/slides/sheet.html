The design

Keep the spreadsheet. Let the LLM fill it in.

An analyst does not re-derive a loan formula for each client. They open a vetted sheet.

Each formula family becomes such a sheet: a Financial Inference Contract, with typed inputs, validation rules, declared conventions, and locked code.

Spreadsheet analogy, implemented as stored contracts. No Excel runs.

Built offline, fixed at run time

250 contracts, three LLM calls each, then lint and smoke tests. None hand-tuned.

The LLM gets three jobs, and only three

1

Pick the sheet

one of the top 4 retrieved, or none

2

Fill the input cells

bind values from the text

3

Flag open conventions

which declared choices the text leaves open

It never computes the answer or freely rewrites the formula.

The design borrows from how analysts already work. You do not re-derive the loan formula per client. You open a vetted sheet, type in the inputs, and its validation refuses impossible values. We write each formula family once as such a sheet, a Financial Inference Contract. The LLM gets three jobs: pick the sheet, fill the cells, flag open conventions. It never computes the answer. If asked: it is an analogy, there is no Excel integration. Contracts are generated automatically, three LLM calls per family plus lint and smoke tests, none hand-tuned.
