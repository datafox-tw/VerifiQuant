The question we ask

When is emitting a number legitimate?

Correct number

The question justifies a number, and the number is right.

Silent wrong

A clean number that is wrong, with nothing to mark it. This is the failure we target.

Named exit

The system stops and says why: refuse, ask, alert, clarify, or warn.

The goal: turn silent wrongs into named exits, while keeping as many correct numbers as possible.

VerifiQuant · ICAIF ’26

4

So the question is not how accurate the system is. It is when a number may leave at all. A correct number is good. A named exit is acceptable and auditable. A silent wrong is the expensive case. The whole design is about moving responses from the middle column to the right one without emptying the left one.
