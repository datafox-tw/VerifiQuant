Two separate tests outside the library. Left: we rebuilt the library from 50 formula families, which leaves 199 questions whose family is missing. VerifiQuant abstains on 89% of them, against 20% when the family is present. R-PAL abstains on half a percent and is right 95% of the time from memory, with no signal when wrong. So out of library we are not more accurate. What we give is a scope signal. If asked: the silent-wrong rate there is not lower, 4.0 versus 4.5%, and selective accuracy is 63.6 versus 95.5%. This is out-of-library within the same benchmark ontology, not open-world generalization. Right: five finance-trained annotators labeled 80 natural queries blind. The ordering holds, but only the gap to plain R-PAL is significant.
