Safety and utility on one picture: clean coverage across, trap false acceptance up. The ideal is the lower right. The hollow points answer a fair question: does the gain just come from splitting the prompt into stages? Staging alone reaches 15.8%, but only by refusing much more, at 67% coverage. Staging plus the contract text reaches 8.8%, level with us, but covers only 75%, mostly because its own programs fail to run. So staging over what the contract declares lowers false acceptance, and running the contract’s own code keeps coverage. Priced against R-PAL plus, each trap number avoided costs 2.0 correct clean answers for VerifiQuant, 3.1 for Staged+Spec, 6.8 for Staged.
