The funnel runs left to right. Retrieval is BM25 over contract metadata, top four. Three LLM steps, in orange, alternate with code steps, in blue. Select picks one of the four, or none. Bind copies values from the text into typed inputs. Then code checks that every required input is present and that the declared boundaries hold. The ambiguity step asks whether a declared convention is still open. Only then does the contract’s own code compute. The letters on top are the same N, M, F, E, I, C from the taxonomy.
