This is the real loan contract, drawn as a sheet. Typed inputs are the cells the LLM fills: principal, rate, term. Data validation is code: principal must be positive, the rate must stay below 1.0. Declared conventions carry options. Rate scale is HARD because it changes the computation, so we ask. Payment timing is SOFT because it changes how you read the number, so we answer and warn. The locked Python code computes 1,498.88. The query is illustrative. 1,498.88 is what the card’s own code returns for it.
