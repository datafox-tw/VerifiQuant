Named exits

Every stop says why

N · refuse

No candidate, or the top score is too low. Or no candidate fits.

M · which one?

Several contracts fit. It asks the user to choose.

F · ask

Names the missing required field and asks for it.

E · alert

Names the violated check and the bound value.

I-HARD · clarify

Offers the declared options, then applies a verified edit.

I-SOFT · warn

Returns the number with a warning about the open convention.

Every path writes a DiagnosticReport: the contract, bound values, checks passed, and why it stopped. Deterministic steps replay from the stored binding.
