This is not an accuracy paper. On 250 well-posed questions R-PAL reaches 96.8% and we reach 81.2% at 84% coverage. Our silent-wrong rate is close to R-PAL’s, 2.8 versus 2.4. The K = 3 row is an upper bound: up to two clarification turns from an oracle that knows the intended computation but never the answer. If asked about the clean set: it is in-library by construction, so it measures routing, binding and gating, not deriving an unseen formula. Runtime: 12.2 s per question versus 10.5 s for plain R-PAL, about 1.2 times. Five-sample self-consistency takes 38.1 s.
